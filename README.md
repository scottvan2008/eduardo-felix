# Diario de um Criptolouco · Eduardo Felix

Landing page estática em português brasileiro, feita com HTML, CSS e JavaScript mínimo. Sem framework, instalação, etapa de build ou analytics.

## Prévia e publicação

Abra `index.html` no navegador ou execute `python -m http.server 8080` nesta pasta e acesse `http://localhost:8080`. Para publicar na Vercel, use o diretório raiz e o preset “Other”, sem comando de build. Nenhuma publicação foi realizada.

## Organização

- `index.html`: conteúdo, SEO e FAQ nativa com `details`.
- `styles.css`: identidade visual, responsividade, CTA fixo no celular e suporte a movimento reduzido.
- `script.js`: entrada suave das seções, mantendo o conteúdo acessível sem JavaScript.
- `assets/`: retratos fornecidos e marca/favicon SVG original. Retrato do hero exibido abaixo de sua largura original de 372 px; foto de apresentação com carregamento adiado.
- `source/` e `BRIEF.md`: referências locais ignoradas pelo Git, assim como `.vercel`.

Conteúdo educativo, sem promessas de resultados. O aviso de risco está no rodapé e na FAQ.
